FAQ

Questions

Does it include a backend?

No. Courses Kit Pro is frontend only and runs on sample data, so you can choose your own backend. All data calls live in src/services/ with notes on what to connect: auth, courses, progress, payments, video storage and push notifications.

Does it work on iPhone, Android and the web?

Yes. It's one Expo codebase that runs as a website and as native iOS and Android apps, with layouts for phones, tablets and desktops.

Can I use it for a client project?

Yes. One purchase covers one end product: one website and its companion apps, for yourself or one client. Buy another license for each additional product.

What do I need to know to use it?

Basic React Native or React experience. If you can run npx expo start and edit a TypeScript file, you can rebrand it.

Can you set it up for me?

Yes. CodeWithRuben can connect the backend, payments and video hosting and release your apps to the stores. Get in touch.
