### 5.4 Ownership upgrade (buyout)

| | |

| Offer | Ownership Upgrade (Buyout) |
| Price range | **$8,000 – $15,000** one-time (scope-based) |
| Intent | Full transfer of site, app, code, store listings, and accounts |

## 6. How engagement works

### Public process (home)

1. **Share your idea** — Goals, timeline, tools to replace  
2. **Discovery call** — Scope, users, approach  
3. **Build & review** — Design, develop, QA, check-ins  
4. **Launch & support** — Ship to web / stores, docs, training, included maintenance  

### Hire / start-a-project process

1. Share idea (goals, timeline, budget)  
2. Discovery call (**15–30 min**)  
3. Proposal & kickoff (milestones + pricing)  
4. Build & review  
5. Launch & support  

**Inquiry SLA (marketing):** reply within about **24 hours** on hire-me; contact page also mentions **24–72 hours** for general messages.

### Contract defaults (CWR Service Agreement)

- Work starts when **first payment clears**  
- **Two structured revision rounds** per milestone during the build  
- Client delays (feedback / content / approvals) extend delivery **day-for-day**  
- Deposit non-refundable if client ends early; completed milestone work handled pro-rata  
- Electronic signature via **CWR Client Portal** before work begins  
- Governing law: **California**; venue **Fresno County** courts  
- **14-day** post-launch defect warranty; then as-is unless a care plan is active  
- Liability capped at fees paid; no indirect/consequential damages  
- Change orders billed at CWR’s standard change-order rate (**amount To confirm**)  

**Maintenance lapse pattern (when a plan is attached)**  
Days 1–14 grace → support pause → hosting suspension + reactivation fee → archive / remove / close if unpaid. Export/migration available for a fee unless IP buyout was purchased (**fee amount To confirm**).
